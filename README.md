# travelmap

지홍♥온유 도장깨기 — 둘이 같이 다녀온 시·군을 지도에 하나씩 칠해 가는 웹앱.

- 지역을 눌러 **가고 싶어 / 다녀왔어**로 기록하고, 다녀온 곳은 원하는 색으로 칠한다.
- 같은 곳을 또 가면 여행을 더 남길 수 있다. 여행마다 날짜·메모·사진이 따로 있고 카드처럼 넘겨 본다.
- 붙인 사진은 그 지역 모양대로 잘려서 지도에 들어간다.
- 전체 현황에서 최근 여행과 연도별 타임라인을 본다.
- 제목 아래 디데이 배지(2024.09.13부터)를 누르면 다음 100일·주년까지 남은 날을 보여준다.

## 저장과 잠금

기록은 Firebase Realtime Database에 저장된다. 처음 화면에서 정한 비밀번호로 기기 안에서 열쇠를 만들고,
기록은 그 열쇠 아래에만 둔다. 비밀번호를 모르면 기록 위치를 알 수 없고, 비밀번호를 잊으면 되찾을 수 없다.

보안 규칙은 [`database.rules.json`](database.rules.json)을 Firebase 콘솔 → Realtime Database → 규칙 탭에 붙여넣어 게시한다.
